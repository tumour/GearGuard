# GearGuard

Protects your equipment set items from being accidentally sold to vendors.

## Features

- **Bag highlights** — items belonging to any Equipment Set are highlighted with an orange-red border and a shield icon
- **Sell protection** — when you try to sell an equipment set item at a vendor, a confirmation popup appears
- **Tooltip info** — hover over an item to see which equipment set(s) it belongs to
- **Localized** — supports English (enUS) and Russian (ruRU)

## Commands

| Command | Description |
|---------|-------------|
| `/gg` | Toggle highlights on/off |
| `/gg help` | Show help |

## Installation

1. Download the latest release from [CurseForge](https://www.curseforge.com/wow/addons/gearguard) or [GitHub Releases](https://github.com/tumour/GearGuard/releases)
2. Extract `GearGuard` folder into `World of Warcraft/_retail_/Interface/AddOns/`
3. Restart WoW or `/reload`
